🛡 AdminTools — Anti-Cheat & Admin Panel

Forge 1.20.1 mod for Minecraft server administrators.
The mod is optional on the client side: normal players do not need to install it.

Features

✨ Features

🔭 ESP (admin client only)

FeatureDescription
Ore X-Ray ESPShows ores through blocks within a 64-block radius, colored by type
Entity ESPShows players and mobs through walls (blue = player, red = hostile, green = passive)

👤 Admin Tools

FeatureDescription
VanishMakes the admin invisible + indicator [VANISH] blinking on their screen
NoClip AdminSwitches to spectator mode (native noclip), restores the previous mode when disabled
Anti-Cheat AlertsReceives violation notifications in real time

🚨 Anti-Cheat detections (server)

DetectionThresholdDescription
Fly80 ticks (4s) in the airDetects illegal flying
NoClip3 consecutive detectionsDetects movement inside solid blocks
X-Ray35% ores / host rockDetects suspicious mining rates

📊 Top Luck

Player ranking by ratio ores / host rock (stone, netherrack, end stone).

  • Automatic detection of mod ores (Create, Mekanism, Thermal Series, etc.)
  • Correct ratio by dimension (Overworld / Nether / End)
  • Detailed view: bars by ore type + list of all broken blocks

🎒 InvSee

View a player's full inventory in real time (read-only).

Usage

🎮 Usage

Admin panel — key K

Opens a panel with 3 tabs:

  • Features — toggles to enable/disable each feature
  • Players — list of online players, with TP / InvSee / Check buttons
  • Violations — scrollable log of anti-cheat alerts

Commands /at

/at                               → Shows your feature status
/at status [joueur]               → Shows an operator player's status
/at toggle <feature> [joueur]     → Toggle a feature
/at on|off <feature> [joueur]     → Force a feature
/at tp <joueur>                   → Teleport to the player
/at invsee <joueur>               → View the inventory (GUI)
/at topluck [reset <joueur>]      → Ore ranking (GUI)
/at check <joueur>                → Quick info (mode, position, ping)
/at help                          → Full help

Feature names:
ore_esp · entity_esp · vanish · noclip · alerts · fly_detect · noclip_detect · xray_detect

⚠️ Requires op level 2 minimum.

Installation & Build

📦 Installation

Server

  1. Copy the .jar into the mods/ server
  2. Restart the server
  3. Players do not need to install the mod to join

Admin (optional)

  1. Copy the même .jar into the mods/ to their Forge client
  2. Join the server — the panel [K] and ESP features are available

🔨 Build

Requirements: Java 17, Gradle 8.x

git clone https://github.com/Floodfield-Sudio/admintools.git
cd admintools
./gradlew build
# Le .jar se trouve dans build/libs/

Or use DevStudio Pro:

  1. Open the folder admintools/ as a project
  2. Minecraft tab → Forge 1.20.1
  3. Click 🔨 Build

src/main/java/com/admintools/

│   ├── AdminPanel.java         ← Admin panel GUI (K key)
│   ├── ClientAdminState.java   ← Client state (active features)
│   ├── ClientPacketHandler.java← Proxy to open screens from packets
│   ├── InvSeeScreen.java       ← Inventory screen (read-only)
│   ├── TopLuckScreen.java      ← Top Luck ranking screen
